# how to use
paste the contents, of the script you want to use, in the dev tools console of your BT Smart Hub's hub manager page (open using <kbd> <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>I</kbd> </kbd>), and run it by pressing <kbd> <kbd>Enter / Return</kbd> </kbd>!

> [!WARNING]
>
> **some scripts may only work on specific pages!!!**
> each folder is named after the page that they should be used on.
> there is a readme in each folder for more info!
